  一款装备管理应用，记录每一件装备的价格、购买日期与日均花费
</p>

<br>

## ✨ 功能

- 📋 **装备列表** — 以列表或块状视图展示你的所有装备
- 💰 **价格追踪** — 记录每件装备的购买价格，自动计算日均花费
- 📅 **购买日期** — 记录购买日期，追踪使用时长
- 🔍 **搜索筛选** — 快速搜索装备名称
- 🌓 **主题切换** — 支持浅色/深色/跟随系统三种主题
- 📊 **统计概览** — 装备总数、总价值、日均花费一目了然

## 🚀 开始使用

### 环境要求

- Flutter SDK ^3.12.0
- Dart SDK ^3.12.0

### 安装

```bash
# 克隆仓库
git clone https://github.com/QNquenan/DuJi.git

# 进入项目目录
cd DuJi

# 安装依赖
flutter pub get

# 运行应用
flutter run
```

## 🛠️ 技术栈

- **Flutter** — 跨平台 UI 框架
- **Material 3** — Material Design 3 设计语言
- **SharedPreferences** — 本地数据持久化
